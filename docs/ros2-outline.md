  你怎么学 ROS2（结合你刚跑通的东西）

  你背景是硬件+裸机+C++，这套东西对你来说新的是"通信中间件"这个范式，不是语言。建议分五步：

  第 1 步：建立心智模型（1-2 小时，别写代码）
  读官方 Concepts 页，搞清这几个词的关系：node / topic / service / action / message / executor。用你的裸机经验类比：
  - topic ≈ 总线广播（像 CAN 总线，谁都能发、谁都能听）
  - service ≈ 同步请求-应答（像发一个命令等 ACK）
  - executor/spin ≈ 事件循环/中断处理（有事件就调回调，没事件就空转）

  第 2 步：官方教程过一遍（半天）
  按 first-four-weeks.md 里给的链接，做 pub/sub 和 service 两个最小例子。这一步的目的不是"会写"，而是亲自确认：一个 node
  发、另一个 node 收，跨进程、跨机器都能通。

  第 3 步：把 CLI 用熟（这是重点，养成习惯）
  ros2 命令行是你唯一的"示波器/逻辑分析仪"。每次跑节点，都习惯性地：
  ros2 node list          # 有哪些节点在跑
  ros2 topic list         # 有哪些话题
  ros2 topic info /xxx    # 话题的类型、QoS、谁在收发
  ros2 topic echo /xxx    # 实时看数据（= 示波器）
  ros2 topic hz /xxx      # 看发布频率（= 频率计）
  ros2 topic pub ...      # 手动造一个消息（= 信号发生器）
  ros2 service call ...   # 手动发一个请求
